The estimand must state conditioning on the fixed generation/novelty/necessary-bound rules; it is not the unfiltered generator distribution.

Use independent deterministic namespaces for `(graph generation, source relabeling, algorithm randomness, execution order)`. For example, derive integer graph seeds from the first 32 SHA256 bits of `(version, validation, family, canonical parameters, attempt 0…4, validation salt, collision counter)` with a stored collision ledger. Derive four solver seeds independently from `(version, solver, source identity, replicate 0…3)`; pair the same seed index/integer across both algorithms without pretending their random trajectories coincide. Use one frozen random source relabeling per structure, shared by both methods; preserve inverse labels and source insertion order. Additional permutations, if desired, form a separately declared robustness study nested within the same structure, not new graphs. Never take minimum ACL across seeds.

Save every scheduled generator attempt, actual counts, semantics checks, timing and outcome, including errors, timeouts, duplicate groups, count exclusions and unresolved identity. No partial planar output, LFR constraint retry, edge deletion, component selection or lost isolate may salvage a failed input.
