# Bounded transport between endpoint-accessible regions

**Hypothesis.** The exact-domain diagnostic found valid donor relocations, but discarded every state where both endpoints had unused neighbors in disconnected components. The saved-domain classification found no overlooked one-exchange opportunity in any failed query. Continuing relocations that reduce the actual separation between endpoint-accessible regions may cross this obstruction within the existing limits. This is a supplied-state reach test, not a constructor or a novelty claim.

For a private state with unused sites F and original endpoint chains E(a), E(b), define R(u) as E(u) together with every connected component of T[F] adjacent to E(u). Define separation d as the minimum full-target hop distance between R(a) and R(b), or zero when they overlap. The distance may traverse other owners solely to measure separation; an accepted connecting path still uses unused sites only. Endpoint chains remain exactly their supplied sets until final path addition.

**Fixed policy and pseudocode.**

1. Reuse the same 25 selected sealed-edge queries, entry states, protected original contacts P, query ordering and independent validation from the exact-domain diagnostic. Every query starts from its unchanged entry. Recompute the two anchored regions and their separation under the common deadline. Select the smaller region by total site count, breaking ties by endpoint ID.
2. Enumerate donor release sites q adjacent to the selected region, excluding either endpoint owner. Retain the existing four-donor / 128-original-donor-site scope. For every q, construct the exact replacement domain using the current donor's unused frontier, all components after deleting q, and every protected neighbor whose contact deletion loses. Record all domain work and empty domains. Rank releases by full-target distance from q to the other region, then donor ID and q; replacement sites p retain ascending physical-ID order. Finish domain construction before consuming the unchanged proposal prefix.
3. For each q→p exchange, repeat the original donor connectivity and protected-contact checks. Make a private state, recompute its actual unused components, anchored regions and separation, and reject it unless d strictly decreases. Reject any exchange that removes the last unused neighbor of a previously opened endpoint. Record region gains/losses and before/after separation; region size alone is never progress. No neutral exchange is retained.
4. If the new regions overlap, find the deterministic shortest unused-only endpoint path, add it to the lower-ID endpoint, and run the independent original-target gate for P plus the requested edge. Preserve raw late/invalid evidence; only a timely successful gate certifies the repair. Otherwise retain the state for continued transport, even when both endpoints already have unused neighbors. Deduplicate exact changed-chain states. Rank the next beam by `(separation, -smaller_region_size, changed_donor_count, trace)`.
5. Keep depth 4, beam 8, 64 attempted replacements per state, 512 per query and 30 seconds per input, including setup, component searches, full-target distance searches, domains, sorting, private copies, unsuccessful attempts and certification. Keep all excluded query IDs, interrupted state records and cap reasons. Outside donors remain frozen; no incumbent evolution, additional query, constructor, MM call or increased cap is included.

**Tiny falsifier.** Use source edges `{(0,1),(0,2),(1,3)}` and entry chains `0:[0], 1:[3], 2:[1,7], 3:[2,8]`. Target edges are `{(0,1),(0,7),(1,7),(1,2),(2,3),(2,8),(3,8),(1,4),(7,4),(2,5),(8,5),(3,6)}`. First move donor 2 from site 1 to 4: endpoint 0 opens into the isolated unused pocket `{1}`, while separation falls 3→2. A second move of donor 3 from 2 to 5 opens an unused path `[1,2]` and gives separation zero. Require depth-one failure, depth-two certification, original P preservation and unchanged input. Retain the unique-contact negative and final-deadline checks, and independently test region/separation arithmetic on tiny target graphs.

**Self-critique and supplied-state falsifier.** Strict distance descent is deliberately restrictive: equal-distance preparation, temporarily shrinking access and joint contact changes can be necessary. The older two-exchange fixture demonstrates useful preparation with no initial separation decrease, so its rejection is a documented limitation, not an implementation error. Consuming p can undo an apparent approach, making post-exchange recomputation essential. Those recomputations may exhaust the same deadline before useful depth is reached. Reject this fixed policy if it certifies no previously failed query, or if its additional work prevents a useful bounded test. Report all four inputs and all 25 outcomes; distinguish newly opened pockets, strictly progressing retained states, certificates and whole-source validity. Do not infer a complete constructor or MM improvement from a local repair.
