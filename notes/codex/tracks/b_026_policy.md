# B026 before-code contract: fresh construction with mobile contact boundaries

**Status: design for root review; no implementation or calls.** Follow the [strategic decision](../strategic_review_20260909.md). Standalone `factored/mobile_tree_construction.py:contact_embed(source, target, *, timeout=60.0, deadline=None, seed=0)`, descriptor `mobile-tree`, configuration `{}`. Standard library only; no inherited constructor, MM/busclique, independent restarts, supplied embeddings, source-family dispatch or target-region partition.

**Hypothesis.** Jointly rebuilding a whole owner while shortening its neighbors' contact-only branches can clear overlap and produce short sparse chains within one trajectory. Continuing this operation after feasibility addresses a limitation of B023–025, which stop at first feasibility plus deletion. This deliberately shares a mechanism with A's proposed valid-state reconstruction, but tests fresh construction without A's filled core. The roots/shared paths/movable boundaries are established ideas, not a novelty claim or a stock-MM transcription. B022's fixed outside owners and small root pool are not retained.

## Representation and initialization

Accept finite simple undirected integer-labeled graphs, as adjacency mappings or the existing graph API. Reject malformed inputs, `|V_source|>|V_target|`, nonpositive/nonfinite timeouts, and noninteger seeds. Normalize once inside the common deadline. Maintain immutable connected nonempty site sets for placed owners, a deterministic BFS spanning tree per set, occupancy sets `owners[q]`, and **one shared oriented actual target-edge witness `(p_u,p_v)` for each source edge whose endpoints are placed**. Orient by numeric source rank; both endpoints of each shared record refer to the same physical coupler. Extra physical contacts are allowed.

Numeric sorted IDs define canonical source/target indices. Separate `Random(seed)` instances shuffle each sorted vector once, defining source and target tie ranks. Target adjacency follows target rank. No fresh random draws or tie changes occur during sweeps. Heap ties use `(distance, source_rank, target_rank)`; a first equal-distance predecessor is retained. A BFS uses target-ranked neighbors, rooted at the lowest-ranked protected terminal (or the explicitly specified singleton anchor).

Start with no placed owners. Repeatedly choose the unplaced owner maximizing `(number of placed neighbors, original degree, -source_tie_rank)` and run the same visit below, with its old tree absent. This completes a source component before starting a disconnected one. With no placed neighbors, choose the singleton minimizing `(node_cost, -target_degree, target_rank)` over allowed sites. This is placement on the whole target, not a fixed initial footprint. Disconnected targets are allowed; inability to connect to the selected target component is a recorded heuristic failure, not a global infeasibility claim. Isolates receive nonempty sites by the same rule. Empty source returns the valid empty embedding.

During initialization, all edges within the placed subset remain witnessed. Edges incident to unplaced owners are separately counted as unplaced obligations. A completed `no_joint_root` during insertion ends initialization with failure; in later sweeps it skips that visit while retaining the incumbent. An interrupted visit ends search and proceeds to finalization. During a private visit, contacts with its removed owner may temporarily disappear; **no completed commit loses a previously represented original contact**. Once all owners exist, missing contacts are forbidden across commits and overlap is the only feasibility defect. This intentionally differs from B023's persistent missing-contact states. A valid minor fits this representation; the restriction on intermediate transitions may still obstruct search.

## One coordinated visit

1. Privately remove the visited owner `u`. Snapshot the shared witnesses of every other represented edge before changing any neighbor. For each placed source neighbor `v`, protect its endpoint of every witness `v–w` with `w != u`. Retain the union of paths in `v`'s deterministic BFS tree connecting those protected sites; with no protected sites, retain only its lowest-target-rank old site. All other old sites of `v` become available. Neighbor processing follows source tie rank. This preserves both endpoints of neighbor–neighbor contacts even when several neighbors are trimmed together. Shared terminal sites are deduplicated for routing, while all logical-edge labels remain protected.
2. Freeze these retained trees and every other owner for the rest of this visit. For each required neighbor `v`, form boundary `B_v = {q: (q,p) is a target edge for some p in retained(v)}` intersected with allowed routing sites. A boundary seed records its lowest-ranked eligible endpoint `p`; overlap alone is never a contact. In feasibility, every target site is allowed. In quality, only sites unoccupied by retained owners are allowed. Thus the rebuilt owner is disjoint in quality.
3. Let retained occupancy be `k(q)`. In feasibility the positive integer node cost is `c(q)=1+lambda(q)*k(q)`, with `lambda(q)` initially one. In quality every allowed site's cost is one. Run interleaved multi-source Dijkstra searches from all `B_v`, with inclusive node costs: seeds have distance `c(q)` and relaxing predecessor `p` adds `c(p)`. When root `r` is settled for all `d` neighbors, evaluate `J(r)=sum_v D_v(r)-(d-1)c(r)`. Select the root minimizing `(J(r),target_rank(r))`.
4. Exact early stopping bounds routing work without a root cap: keep the best complete root score `J*`; stop when every remaining live heap key exceeds `J*`. Any root not yet settled for all neighbors has some `D_v(r)>J*`, and `J(r)>=D_v(r)` because every other inclusive path contributes at least `c(r)`. It therefore cannot tie or improve the winner. Process equal keys before stopping to resolve ties. Exhausting all queues without a common root is `no_joint_root`; interruption is unknown, never infeasibility. Target paths are unrestricted geographically.
5. Start the rebuilt set at that root. Visit neighbors in source tie order. If a real target coupler already connects the growing set to the retained neighbor, no path is needed. Otherwise select the growing-set site with minimum `(D_v(q),target_rank(q))` among settled labels, follow its predecessor path to the boundary seed, and union that path. Unsettled labels cannot beat the original root's distance under the stopping rule. Positive costs ensure simple predecessor paths; unions remain connected even if paths rejoin the current set. This greedy shared-path construction does not minimize actual union cost.
6. Select canonical actual couplers for the new `u–v` contacts, by endpoint target ranks. Preserve every other shared witness during this visit. Trim the new tree to the subtree connecting its selected terminals, retaining a singleton when it has none. Recompute deterministic trees and certify all changed chains and incident original-edge witnesses. Calculate actual global `Q=sum |C_u|` and `O=sum_q max(0,|owners[q]|-1)` through changed-site deltas, including unchanged owners sharing those sites. No full owner-map rebuild or repeated global contact validation per neighbor is required. Commit only after the final clock check; otherwise discard the entire private visit.

This move shifts neighbor→visited-owner boundaries through pruning and rebuilding. The reverse direction occurs when that neighbor is visited later; there is **no additional post-route flip-back policy**. Witness choices remain revisable when either endpoint is visited, but other incident contacts constrain each neighbor's trimming. There is one root minimizing the declared joint-distance proxy, not a beam of actual-Q candidates.

## Acceptance, prices and stopping

During initialization and overlap feasibility, accept every complete certified visit, including one that increases Q, O or weighted route cost. This avoids silently reinstating B025's failed mandatory current-energy gate; it does not assert that unconditional acceptance is optimal. After initialization, make complete owner sweeps in descending current owner-overlap incidence, then descending chain length, then source tie rank; freeze that order at sweep entry. After each completed feasibility sweep, atomically increment `lambda(q)` by `max(0,|owners[q]|-1)` for currently overlapped sites. No price update follows an interrupted sweep. Update prices once after completed initialization if overlap remains. Price preparation and publication are timed and counted. There is no reset to an earlier overlap state.

On first `O=0` with all original edges represented, perform a full original-graph validation and enter quality permanently. Freeze prices. Quality visits use descending chain length then source tie rank, fixed at each sweep entry. Publish an original-valid proposal iff `Q_new<=Q_current`; changed equal-Q states are allowed and separately counted. Rejected larger-Q proposals retain the valid incumbent. Stop after a quality sweep with no changed commits, at validated `Q=|V_source|`, or at the search deadline. Neutral cycles can consume the deadline; there is no hidden pass limit. Output is the current valid state, not selection among independent starts or constructors.

## Time, finite work and receipts

`D=min(begin+timeout, caller_deadline)` when supplied; there is no hard20s clamp. Setup, copies, normalization, searches, certificates, diagnostics and output materialization are charged. Use `R=min(1s,0.05*max(0,D-begin))` as an explicit finalization reserve and stop search at `D-R`. This retains a disclosed reserve used in earlier B wrappers; it is not a guarantee that new-size finalization fits. Full original validation and output materialization must finish before D, or return no credited embedding. Report reserve usage and any valid incumbent lost to late finalization. Root's next screen supplies a common60s envelope; public tiny gates use5s.

Counters are diagnostics, **not a work admission gate**: no20M, per-query100k, local5s, root-pool, pass or restart cap. Check clocks before/after sorts and stages, on each heap pop and at least every256 scanned adjacency/site/owner entries. One visit explores at most `d|V_target|` settled labels and `d` scans of target adjacency, often less under the proved stop; memory is `O(d|V_target|+Q)` worst case. Use sparse per-neighbor labels/parents and reuse immutable normalized adjacency. Whole-call time bounds repeated visits. High-degree searches can still monopolize the call; their interrupted state and explored-label counts are retained.

Record per-phase wall/CPU where available and counts of source/target scans, labels settled, heap pushes/pops, shared-path additions, neighbor sites released, cross-owner transfers, actual Q/O, first-valid time/work, feasibility increases, strict-Q/neutral quality commits, rejected complete proposals and interrupted visits. Keep first initialization/final snapshots and the last interrupted stage/root/neighbor; retain aggregate counts for every visit and only the first16 detailed visit records to avoid unbounded diagnostic overhead. Record this trace truncation explicitly. Full-Q improvements retain time/Q progress points. Partial query records cannot commit chains, prices, witnesses or occupancy. Independent final validation remains the output authority.

**Self-critique.** The global representation includes valid minors, but all-contact completion plus protected other-edge witnesses may restrict useful trajectories. One minimum-distance root and greedy sharing can miss a better actual-Q tree; feasible neutral motion can cycle. Linear occupancy/history prices are a heuristic, not a convergence proof. Early stopping preserves the root proxy exactly but does not guarantee MM-scale Python runtime. A/B intentionally share this ownership mechanism while testing different initialization/feasibility questions, and C's frontier construction remains separate. No novelty or class-level superiority is claimed. Distinguish unexercised/censored moves, completed moves rejected by quality acceptance, actual improvements erased by downstream behavior, and complete successes with still-poor Q before deciding what any failure means.
