# Proposed C010 computation-allocation ablation

**Design only; no code or calls.** C010 remains retired. Its [six failures](c_010_results.md) exhausted nineteen million conservatively charged units in 0.318–0.653 seconds, leaving most of the fifteen-second wall allowance unused. The hypothesis is that this stopping rule prevented useful complete construction, rather than that the placement/splitting neighborhood necessarily cannot complete these inputs. This is a computation-allocation test, not a new placement mechanism.

**One controlled change.** Compare fresh fixed C010, a wall-limited C010 ablation, and fresh MM on all eight unchanged C inputs: seed 0, ideal Z12, hyde03, fifteen seconds per call, twenty-four calls. Keep every source/target order, seeded tie, exact-domain calculation, 32-site ranking prefix, four-clone/four-attempt revision, split partition, Q bound, publication rule and absence of cleanup unchanged. Each arm is a separate solver call; no fallback or pooled choice of embeddings. The work-limited control retains its nineteen/twenty-million limits. The treatment disables **both** search and final work-denial predicates, retaining all integer work counters. Leaving the final twenty-million limit active would invalidate the treatment as soon as the longer search crossed it.

```text
Run the same initialization and greedy placement/splitting trajectory.
At each operation, record the same work charge and perform the same clock checks.
Control: deny operations exceeding the active work limit, as before.
Treatment: count them; record the first would-deny event without stopping.
Stop search at the unchanged absolute deadline minus 0.5 seconds.
Use that same final reserve for snapshot, output and independent original validation.
Credit only a complete clone placement whose original minor and output finish on time.
```

The treatment records its first crossing of the nineteen-million search threshold and twenty-million cumulative threshold, including units before the operation, requested charge, phase and elapsed wall. These are diagnostic thresholds, not falsely reported active limits. Compare the fully recorded decisions and charges in each fresh control/treatment common prefix; retain partial records without inventing unsaved state equality. No constructor is rerun to obtain a matching trace. Unexpected prefix divergence would undermine the controlled comparison and must be reported before interpreting reach.

**Interruption and accounting.** Keep the same absolute clock checks, private rollback, fatal-error handling, external worker watchdog and final late-output rejection. Disable work denial during finalization too; do not enlarge the 0.5-second reserve or fifteen-second deadline. A larger clone state may make that reserve insufficient. Preserve a late/partially materialized diagnostic map when available, but return TIMEOUT or ERROR without quality credit; do not complete validation after the deadline and retroactively credit it. First-valid Q needs the same independent original-source/target gate. Larger histories and output serialization can consume memory or worker cleanup time; those failures remain outcomes, with no silent receipt truncation. Construction remains finite: each published visit adds one placed clone or one clone, so at most `2*target_n-source_n` visits can publish, plus a terminal failed/interrupted visit. Clock-limited execution may stop much earlier.

Before any screen, only focused budget-mode checks are proposed: unchanged control denial versus treatment continuation with identical charges, and deadline/rollback/final-validation/fatal non-credit after a synthetic threshold crossing. No extra constructor fixture or supplied-state repair is needed. Preserve fixed C010 bytes and prior failures; the ablation receives a separate frozen identity. All three arms use separate paired processes on the same host, with the existing deterministic per-input method shuffle.

**Self-critique and cheap falsifier.** More computation may only accumulate failed revisions or unnecessary splits. A wall timeout remains censored evidence, not proof of global clone inadequacy; an early unresolved exit gives stronger evidence about this fixed neighborhood. Conservative work units are not CPU time. The decisive observation is **additional timely, independently valid complete inputs**, with final Q and measured solver/CPU/process cost. Smaller missing-edge counts or more placements alone do not support the hypothesis. Retain all eight inputs and every failure.

One proposed screen is sufficient: no additional timely completion beyond the fresh control rejects unused-runtime recovery on this panel. Any extra completion supports that narrow mechanism claim, but continuation still requires the unchanged **>=6/8 timely valid**, **>=3 Q wins/ties against common timely MM** (optimal ACL=1 ties allowed), and **median common-pair solver ratio<=3**. Report these decisions separately. Passing would justify broader development evaluation, not rehabilitate the retired fixed C010 policy or establish generalized performance. No cap retuning or follow-up experiment follows automatically.
