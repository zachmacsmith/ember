# Exact replacement domains before the directed-vacancy prefix

**Hypothesis.** The first directed diagnostic spent 1,433 of 1,442 attempts on disconnected or contact-losing replacements. Exact local constraint filtering may reveal useful replacements beyond that invalid prefix without increasing the query, proposal, beam, depth, owner, site or time limits. The complete query's first 64 of 13,368 raw proposals were disconnected; whether it has any admissible domain is unknown before this test.

For a donor chain C and released site q, compute connected components C_i of C minus q. Let L contain its protected source neighbors whose contact disappears on deleting q. A replacement site must belong to

`D = unused ∩ N(C) ∩ (intersection_i N(C_i)) ∩ (intersection_v_in_L N(chain_v))`.

The original free-boundary restriction N(C) remains, including for singleton donors. Empty intersections impose no additional constraint. For a nonempty remainder, one new site connects it exactly when it touches every component; for an empty remainder the replacement is a connected singleton. A lost protected contact is restored exactly when the new site touches the relevant neighbor chain. Existing protected contacts not in L persist because only q changes ownership. These are exact connectivity/contact constraints, not a feasibility theorem for the requested missing edge or for the entire minor.

**Pseudocode.** Reuse the first diagnostic's fixed endpoint distances, sealed-edge selection, strict vacancy-distance condition and donor scope. Enumerate eligible release sites in the same order. For each, construct the exact replacement domain from current private ownership, recording components, lost contacts, old frontier size and domain size. Reject empty domains explicitly. Rank surviving `(donor,q,p)` proposals in precisely the old relative order, retain the existing full connectivity/contact checks, and run the unchanged private search and final original-target certificate. Freeze all outside ownership and the supplied entry as before.

Use the identical four C006b final states and the same eight-edge prefix (one query on complete), depth 4, beam 8, four donors/128 original donor sites, 64 attempted replacements per state, 512 per query and 30 seconds per input. Domain construction, every rejected q, component traversal, contact-boundary lookup, copying and sorting are charged to that deadline and separate work counters. No persistent cross-query cache, additional seeds, query selection change, incumbent evolution or constructor/MM run is included. Capture every excluded edge and interrupted/capped operation.

**Cheap falsifier.** Independently enumerate tiny original-target replacement possibilities and require exact agreement with D, including articulation releases and singleton donors. Reuse the occupied positive, unique-contact negative and two-exchange fixtures. On supplied states, report whether the complete query's domains are all empty, nonempty but still fail downstream, or too costly to finish; compare certified repairs and exact generation/filtering counts across all four inputs. Do not interpret empty domains under the fixed donor/release scope as impossibility of joint rerouting.

**Self-critique.** Filtering cannot restore contacts when no one-site replacement can do so, and it does not solve isolated free pockets after a donor move. The extra local scans may cost more than the discarded proposals. Caps still constrain admissible proposals, and the source-ID prefix still limits which missing edges are tested. This is a separate supplied-state diagnostic of sound constraint filtering; novelty, full-constructor performance and generalization remain unproved.
