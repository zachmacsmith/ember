This amendment resolves implementation choices before writing or executing the
candidate. The proposed focused packet has not run. Novelty remains unproved.

**Hypothesis category: neighborhood and representation.** A valid partial minor
can escape a blocked birth by coordinated displacement of existing contacts,
without the fragmentation/contact debts that defeated B030. This is a conditional
geometry operation, not a new price, temperature or score. No empty band means
the geometric domain has failed; available valid maps followed by no clean birth
mean this neighborhood/order is insufficient; deadlines in map/BFS/union scans
identify cost; successful recovery followed by high final Q identifies bridge
cost or the ordinary greedy path choice. These observations are distinct. A
successful geometric fixture alone cannot establish useful complete embeddings.

**Ordinary birth.** Source order is one BFS forest: highest degree first, with a
single seeded source rank breaking ties. A seeded target rank fixes all adjacency,
terminal and root ties. The center minimizes squared physical-coordinate distance
to (12,12), using `(w,2z+j+1/2)` for u=0 and swapped axes for u=1. Component roots
use the nearest free site by target graph distance from that center. For each
introduced neighbor, clean multi-source BFS visits its terminals and free sites;
all other owners are blocked. Examine every free root with a path to every
neighbor. Minimize the union of these **chosen canonical BFS paths**, excluding
occupied terminals. This is not a globally minimum Steiner tree. A partially
materialized union may be abandoned once its nondecreasing cardinality cannot
beat the completed private winner, with target-rank ties fixed in advance.

**Transport and selection.** Recompute owner spanning trees and original-edge
witnesses from the entry prefix with the fixed ranks. Enumerate the finite 264
directed cut pairs, rejecting occupied destination bands and failed actual-edge
checks. Skip an identical ownership map, including A=0 with an empty shifted
slab; it is not a second ordinary query. Sort feasible private maps by exact
bridge increase and then direction/A/B. The best completed current-birth
transaction is the only provisional incumbent during transport enumeration.
Its score is actual total Q, then direction/A/B and root rank. The public valid
prefix remains unchanged. The local lower bound `bridge Q + 1` can skip later
maps that cannot improve this incumbent. Neither that bound nor root-union
pruning is a work cap. No independent completed constructor supplies an output.

**Publication and clocks.** A complete private transaction contains the full
new prefix, including any transport and birth. It becomes public only after the
unchanged structural validator accepts its induced source graph and the clock
check succeeds. Interruption leaves the public entry unchanged. A scan cutoff
may salvage an already completed private **full-source** transaction only if
full validation and output preparation finish before the absolute call deadline;
an interrupted partial-prefix transaction remains uncredited. A fatal exception
always yields ERROR with no embedding, including after a valid candidate exists
or the clock overruns. Ordinary declared input failures remain distinct.

Time begins before lazy support/validator imports. Search reserves
`min(1 second, 0.05 * timeout)` for finalization; absolute deadline is the minimum
of the supplied deadline and start+timeout. All setup, witnesses, maps, copies,
scans, validation and output preparation are charged. The deadline is the only
search limit. Record exclusive phase wall time, counters, every scalar birth and
transport query receipt, published-prefix Q, and complete first-valid/incumbent
Q events separately. A prefix Q is never reported as complete-embedding ACL.

**Focused new-risk packet.** On the saved public ideal Z12 adjacency, verify the
two-rail common-singleton fixture and a truly sealed owner's leaf insertion;

an occupied far band, a missing required image coupler and an identical map.
Use the original independent oracle for minors, with native dependency isolation.
Inject interruption and a post-candidate fatal error to check atomic publication
and no false output credit. These are small operation fixtures, not development
constructor screens or a replacement correctness framework. Root reviews source
and frozen bindings before its one execution; preserve any failure without rerun.

g0013/g0301/g0302/g0305/g0308/g0309, seeds 0/1, full B031, ordinary-only, A061 and
