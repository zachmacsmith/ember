# Proposed continuation between endpoint-accessible unused regions

The saved-domain test rules out missed one-exchange repairs for every failed query's recorded domains. A component-aware reordering of that same terminal policy is therefore not the next useful experiment.

Propose retaining an intermediate free pocket that touches an endpoint even when it cannot yet reach the opposite endpoint. For a private state, compute each endpoint's reachable unused components. Treat its original chain together with those components as an anchored region. Continue exact-domain donor relocations near either anchored region, maintaining connected/disjoint chains and every protected original contact, until an exact unused-only path connects the endpoints or the unchanged depth/beam/work/deadline limits stop the query. Outside donors remain frozen; final endpoint growth still requires the independent original-target certificate.

A candidate ranking should use separation between these anchored regions, rather than distance from an endpoint to an arbitrary unused site. Bounded neutral preparation must remain possible: a relocation can make a useful donor accessible without immediately reducing region separation. The existing two-exchange fixture exposes this issue, so imposing a new strictly decreasing separation requirement without testing it would be unjustified. Exact-state deduplication and the existing depth/beam caps bound neutral continuation; no annealing or independent restarts are proposed.

Before implementation, specify the exact local donor/release eligibility, ordering and neutral-state score. First extend the tiny fixture to contain an intermediate endpoint-adjacent pocket disconnected from the opposite unused region, then require a second contact-preserving exchange to connect them. Falsify the policy on the same supplied states and fixed caps before any full constructor screen. Component recomputation may dominate runtime, and preserving all contacts at every step may still exclude necessary joint rearrangements. This is a design proposal for review, not a frozen execution policy or a novelty claim.
