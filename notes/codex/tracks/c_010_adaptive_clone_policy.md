# C010: fixed adaptive-clone policy before implementation

This specifies the accepted [design](c_adaptive_clone_constructor_proposal.md). Only private tiny primitives/checks are authorized locally; the public constructor and C8 remain uncalled until root freezes the screen.

Use supplied source/target node order as integer ranks. Original edges have lexicographic endpoint ranks and immutable IDs. Initial clone IDs equal source ranks; each split keeps the old ID and appends one ID with the same owner. A single `Random(seed)` shuffles target ranks once. There is no subsequent random draw or architecture/family rule.

For an unplaced clone x, let G(x) be every target site of degree at least its current auxiliary degree, A(x) the intersection of G(x) with target neighborhoods of **all placed auxiliary neighbors**, and D(x)=A(x) minus occupied sites. These are exact bitsets over the full target. Select an unplaced clone by most placed neighbors, then smallest |D|, largest auxiliary degree, original-owner rank, clone ID. Selection considers every eligible unplaced clone; interruption publishes no selected clone.

If D is nonempty, score its first 32 members in the one shuffled target order. For each q, temporarily place x at q and compute the exact D of every still-unplaced auxiliary neighbor. **Maximize minimum remaining support, then total support**, finally prefer earlier rank **in that single seeded target permutation**, not original numeric target order. With no unplaced neighbor both scores are zero. Zero future support is a scored warning, not a rejection; exactly one best site is proposed. The 32-site prefix limits ranking, never defines emptiness. Complete the prefix before proposing; interrupted ranking publishes nothing.

If G is empty, classify a degree conflict and skip revision. Otherwise D empty is adjacency conflict when A is empty, occupancy conflict when A is nonempty. Build a conflict pool from every placed auxiliary neighbor, newest placement first, followed by distinct occupants of A, newest first; ties by clone ID. Thus A is evaluated before the occupied mask. Take its first four pivots. For each, release that pivot and up to the next three pool members cyclically, retaining every other placement. On this private view place x first, then the pivot, then remaining released clones by the ordinary selection/ranking rule. No alternative target branches are revisited. A complete, locally certified block publishes once; a failed or interrupted block restores the entry exactly. Attempt ordering, released IDs, known costs and failure stage are retained. These four attempts are bounded greedy moves, not a global CSP/backtracking solver.

After failed revisions, an **unplaced** x can split only if auxiliary degree>=2 and total clone count<target size. Sort its incidences by increasing support `|(G(x) minus occupied) intersect boundary(neighbor)|`, where a placed neighbor's boundary is its target neighborhood and an unplaced neighbor's boundary is the union of target neighborhoods of its exact D. Ties use stable original-edge IDs, followed by internal-edge creation order. Alternate incidences between old and new clones, starting with old; add one new internal edge. Each incidence moves exactly once, including older internal edges. The owner-induced tree and every original-edge identity are invariant. Build the change privately; charge it and check the deadline before publication. No eligible split means explicit unresolved failure. No failed revision is a lower bound on necessary Q.

Every changed placement receives a fresh increasing placement timestamp; every published placement/block/split increases a state generation counter. Domain/support values are recomputed from the actual view and current auxiliary graph; no geometry cache crosses publication. There is one evolving graph/placement, no restart, exact solve, complete chain-domain list, or cleanup. Return only after every clone is placed and independent original-source membership, connectedness, disjointness and coupler checks pass.

The absolute deadline is min(entry+timeout, supplied deadline). Search stops 0.5 seconds before it and at 19 million units, leaving the full 20-million bound for snapshot/output/final validation. For shorter allowances the search interval may be empty. Charge each node/edge/adjacency/candidate/record examination and copied member. Each target-bitset intersection/union/complement/count/copy costs ceil(target_n/64) units (minimum one); set-bit enumeration charges examined sites as well. Charge sorting input records plus a conservative `k*ceil(log2(k+1))` comparison allowance. Check clock at stages/publications and at most 256 additional charged units apart. Diagnostic serialization by the harness follows its existing convention; our snapshot/materialization work remains inside the solver clock.

Publication has no fallible computation after its final clock/work check: prepared objects replace the old state. Interrupted proposals retain completed diagnostic prefixes and never mutate the public state. Search interruption may still return an already complete, timely original-valid state. Final validation/copy crossing the absolute deadline retains diagnostic maps but credits no embedding. Unexpected exceptions are fatal ERROR even if a valid map exists; only explicit parameter/input errors are ordinary FAILURE. Preserve exception and stop records; no final gate may erase them. Report search versus final wall/work, Q versus placed sites, original missing edges/connectivity, all conflict/split/revision prefixes and reached generation. Incomplete assignments are never called original minors.

Focused checks are exactly three groups: (1) owner-tree/original-edge preservation and known singleton/triangle-cycle fixtures; (2) successful/private failed revision and split rollback; (3) work/deadline interruption plus late/fatal/invalid non-credit. No public-constructor call. After review, proposed C8 is sixteen fresh paired calls on hyde03, seed0/15s, unchanged inputs, candidate `adaptive-clones` and MM; continue only with >=6/8 timely valid, >=3 common-input Q wins/ties, and median common-pair solver ratio<=3. All censoring/failures remain reported.
