# Reserved-access initialization: access restored at a contact cost

The fixed initializer passed on all eight development inputs within its five-second per-input limit. Every occupied induced graph remained connected, coarsening produced the required number of connected disjoint regions, and the unchanged assignment satisfied the original full-target degree bounds. Every chain touched the connected unused reserve; the entire unused full-target set was also connected in each result. The saved C006b initial maps had 36–55 sealed chains per input; these counts became zero.

This establishes the proposed initial-access property on this panel. It does **not** establish repair success: all eight initial maps still miss original source edges, and the number of missing edges increases on every input. Reserving 7.0–9.7% of the unchanged active set reduces distinct quotient contacts by 6.8–18.3%. Its occupied partition contact upper bound, 25,666, exceeds 8,001 source edges; this loose bound does not resolve the actual 1,634 missing contacts. Growing through reserved sites could overcome occupied-only limits, but consuming the reserve can destroy its common-access guarantee. No path additions were tested here.

Before execution, six focused test groups passed, including an independent greedy oracle on all 167 centered cases from the 44 connected labeled graphs with at most four vertices, fragmentation/positive fixtures, interruption retention and original-label/access checks. During each input's deadline, the runner checked exact U/center replay and restored the unchanged subset RNG progression. The independent oracle checked nonempty, connected, disjoint chains and physical realization of every claimed original-source contact in P. These partial-contact assignments are valid embeddings of that edge subset; all eight fail full-original-minor validity. Contacts and unused components were separately recounted. There were no initialization failures, timeouts, late outputs or forbidden calls. Per-input work totals 5.450 seconds; total diagnostic wall including serialization was 5.498 seconds. These local costs include preparation, baseline recount and validation, and are not constructor or historical timing comparisons.
