# Proposed directed vacancy transport on supplied partial states

**Hypothesis.** A donor chain can exchange an occupied site near a sealed endpoint for an unused site on its own boundary while retaining connectivity and all already represented original-source contacts. Repeating such directed exchanges may bring a vacancy to the endpoint, enabling a free path for the missing edge. This tests a general ownership repair, not more free-site wandering or a new constructor.

**What is reused conceptually.** C005's `free_safe/free_delta/free_commit` implements constant-Q one-site exchanges, but its search samples releases and admits increases in missing edges under annealing (`quotient_vacancy.py:26–64,99–153`). Track A's `vacancy_repair.py:187–263` uses private contact-directed relocation with depth/beam/owner/site caps to repair a deliberately removed site. Here every intermediate donor exchange must preserve all initially realized original contacts; the target is a missing edge's access obstruction. No existing constructor or vacancy-refiner entrypoint is called. Elementary shifts, swaps and vacancy chains overlap established prior mechanisms; novelty remains unestablished (see `../ownership_exchange_prior_art.md`).

**Fixed policy proposed before implementation.** Use the four original C006b final partial states, independently from the same entry for every query. Classify every missing edge by the number of sealed endpoints. Select at most eight edges per input, ordered by that count (one before two), then canonical endpoint IDs; record every excluded edge. The other missing edges are not silently declared failures or successes. Fix the already realized source-edge set P at the query entry.

Only edges with one or two sealed endpoints are eligible for the eight-query prefix. Compute full-target hop distances to each endpoint chain. In each private search state choose its sealed endpoint with smallest canonical ID. Let delta be the minimum distance from that chain to any unused site. A proposal chooses a donor distinct from both endpoints, replaces its occupied site q with unused p on that donor's free boundary, and requires distance(q, endpoint) < delta. Check the whole replacement chain, nonempty/disjoint ownership, and preservation of every edge in P. This strictly moves the nearest vacancy closer; an endpoint already opened during this query must retain at least one unused neighbor. Endpoint chains remain unchanged until final path addition. Donor changes are limited to four owners and 128 original sites; everything outside those donors stays byte-for-byte unchanged until the final endpoint growth.

Rank proposals by released-site distance to the sealed endpoint, distance to the other endpoint, donor ID, q and p. Rank retained children by remaining sealed-endpoint count, sum of the two endpoint-to-free distances, changed-donor count and the lexicographic relocation trace; deduplicate exact changed-chain states. Use depth 4, beam width 8, at most 64 attempted replacements per entered state and 512 per query. Count every attempted replacement, all adjacency work, copies, sorting, failed predicates and certificates. Keep a common 30-second per-input diagnostic deadline, with no restart or uncharged query setup. A partial proposal is never committed to another query's entry.

After an exchange, if a shortest free-only endpoint-to-endpoint path exists, assign the whole path to the lower-ranked endpoint and run the independent full original-target gate for connectivity/disjointness, every P contact, and the requested new contact. Return the first certified repair in the prescribed search order. Other missing contacts may remain, so report repaired-edge reach separately from complete-minor validity. If both endpoints acquire free neighbors but their free components remain disjoint, this policy stops that branch; it does not add an unrelated free-component search. No cleanup or full C007 run is included.

**Cheap falsifier and self-critique.** First require a tiny occupied-endpoint fixture where additions alone fail but a directed donor exchange plus a free path creates the edge while preserving P, and a fixture where a unique donor contact correctly blocks the exchange. Then apply the fixed query cap to all four supplied states. Zero certified repairs rejects this bounded strict-preservation policy. Repairs justify further mechanism analysis, not candidate/MM quality claims. Strictly decreasing vacancy distance and preserving contacts at every intermediate state may exclude useful joint rearrangements; dense endpoints with unique donor contacts may need a private temporarily incomplete repair. The source-order prefix is inexpensive but does not estimate all-edge reach. No graph family, MM output, or unsaved best state affects the rule.
