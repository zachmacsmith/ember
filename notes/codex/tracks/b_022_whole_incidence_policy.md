# B022: whole-incidence joint reconstruction

**Pre-code proposal, awaiting review.** [B021](b_021_results.md) certifies that all 497 recorded dense B020 scopes retain every selected site. This candidate releases **all original-edge witness bindings incident to two selected owners**, rebuilding both complete trees jointly. Outside chains remain fixed. It changes the move neighborhood and owner schedule, while retaining B019's initialization, prices and acceptance; it is not an isolated neighborhood-only performance comparison. No implementation or calls accompany this policy.

## State and deterministic visits

Use one standalone constructor with B019's integer normalization, source BFS forest, target BFS tree/half-path initialization, isolate handling and original-edge certificates unchanged. Physical ranks remain `Random(seed).shuffle(sorted(H))`. A separate `Random(seed)` shuffles ascending source vertices once to give the owner visit/tie order; canonical `(min(u,v),max(u,v))` order ranks source edges. These choices depend only on adjacency and seed.

Maintain one complete connected/contact-valid private state, allowing overlap before feasibility. In each of at most eight sweeps, visit every owner once. Pair it with the other owner maximizing the sum of current prices on their shared sites, ties by owner visit rank. With no shared owner, pair with its original logical neighbor having largest current chain, then owner rank. An isolate without overlap is already size-optimal and is skipped. An overlapping isolate attempts B019's first-free-site move; if no site is free, use the same pair query. A selected pair need not be logically adjacent.

Freeze outside chains and ownership for one query; delete both selected trees and every incident witness privately. The old trees provide candidate sites but **no retained terminal obligations**. Each incident source edge is now a contact requirement, satisfied only by an actual target coupler between its current endpoint trees. Contact through shared ownership alone is insufficient.

## One bounded joint search

For each frozen neighbor w, construct its distinct physical boundary B_w = union of target neighbors of sites in C_w. For selected owner u, its root universe is its old tree, its old tree's target neighbors, and all B_w for its frozen logical neighbors. Scan/deduplicate these sets inside the query allowance. Root rank is `(incremental site energy, -number of frozen logical neighbors contacted, physical rank)`. Site increment is 1 for an unoccupied site and `1+lambda(q)` when an outside owner occupies it. Keep the first four roots per owner.

Enumerate the at most 16 root pairs in rank order, excluding identical roots. This exclusion is a deliberate heuristic restriction, not a general infeasibility test. Each state contains two nonempty connected trees. Recompute all incident contacts after every union. Rank states by `(number of missing original edges, exact partial E, O, Q, tree signature)`; the signature is the two physically ranked site lists in owner visit-rank order. Deduplicate exact tree pairs and retain at most four states. Partial energy is only a search ranking, never a valid-embedding result.

At each layer expand every retained state once. Select an unsatisfied internal selected–selected edge first if present. Otherwise choose the missing selected–frozen edge with smallest |B_w|, then canonical source-edge rank.

* For a frozen neighbor, run one deterministic multi-source Dijkstra from the selected tree to B_w. Keep paths to the first min(3,|B_w|) distinct settled endpoints; stop once that many settle or the reachable queue exhausts. Costs are zero on own tree sites and otherwise `1+lambda(q)` if any other current owner occupies q, else 1. Heap/neighbor ties use physical rank; retain the first predecessor on equal distance. Each path union supplies one child. A target endpoint actually adjacent to C_w is required.
* For a missing internal edge, the two connected trees are disjoint: overlapping nonsingleton trees would already supply a coupler, and identical singleton roots were excluded. Find the first minimum-cost simple path from the lower visit-rank owner's tree to the other tree; its interior excludes both. Interior sites cost 1, plus lambda when occupied outside the selected pair; endpoints cost zero. Split at the first, middle `floor((len(P)-2)/2)`, and last path edge, deduplicating cut indices. Prefix/suffix unions give at most three children and the cut supplies the logical contact.

Added sites never remove an existing contact, so a child resolves at least its chosen missing edge. There are at most the initial number of incident requirements in expansion layers, four parents and twelve children per layer. After any layer produces complete children, finish that layer and stop; this also applies to the initial root-pair layer. If no child survives, return no proposal. All successful/failed route scans count. Root/path/beam truncation and first-complete-layer stopping are incompleteness, not infeasibility certificates.

For every complete child, choose each incident witness as the first actual coupler by physical ranks oriented with its canonical source edge. Visit owners in visit-rank order, deduplicate terminals, then prune nonterminal leaves with a physical-rank heap, retaining witness endpoints; an isolate retains its root. Certify both resulting trees and every incident original edge. Rank eligible proposals by `(E,O,Q,witness ranks,tree signature)`. Validate the best again, check deadline, then commit chains, bindings, ownership and conflict totals atomically, including conflict totals of outside owners sharing changed sites. No private best survives a query interruption.

## Acceptance, work and rollback

Use B019's exact `E=Q+sum(lambda(q)*max(0,owner_count(q)-1))`. Before feasibility accept strict E decrease only; after O=0 require O=0 and strict Q decrease permanently. Increase prices by current excess ownership only after a complete infeasible sweep: all owner visits must finish, but local query caps do not prevent this update. A global interruption does. Requiring all queries complete applies only to the feasible fixed-point stop, matching B019. Do not compare energy across price updates. One failed/limited query retains the current incumbent.

Keep B019's shared 20M global units, 19M search ceiling, eight sweeps, 100k additional units/five seconds per query, and original caller deadline. Search reserve is `min(1 second,0.05*timeout)` plus at most the remaining one million units. No counter or deadline reset: setup, scheduling, boundary/root enumeration, all Dijkstra scans/children, score/certificate/pruning work, maintenance and final output materialization count. Hash/heap/sort administration stays in elapsed wall. Final credit requires the existing independent original-graph minor validator and timely outer return; otherwise return failure with Q/O, stop reason, completed/limited queries and discarded eligible-proposal receipts. Amortized immutable graph data is reused; no other constructor/MM/busclique code is invoked.

## Falsifier and decision

The fixed joint-versus-single witness is B021's path X–u–v–Y, target edges a–b,x–b,y–b,x–c,c–d,d–y, chains {x},{a,b},{b},{y}. All three selected-incident bindings are released. Joint roots c/d give Q4/O0/E4 from Q5/O1/E6 at lambda=1; with either selected owner frozen, no strict-energy move exists. Root universes include c/d through frozen-neighbor boundaries. This hand argument tests a fixed-price barrier, not necessity over neutral moves or later price epochs. Before the screen, one focused implementation check must recover that proposal, preserve all outside chains, and reject a fully overlapping triangle-on-path as a valid minor. Add only material cap/deadline rollback and affected-owner accounting checks.

Then make one fixed **18-call complete-constructor screen** on the unchanged nine B9 inputs: B022 and fresh stock MM, seed 0, **20 seconds each**, isolated environments on hyde02 with the existing validator. This is a deliberately shorter gate than B020's 60 seconds; historical timing is not compared. Keep all results. Continue only if B022 produces at least **7/9 valid timely embeddings** and uses no more Q than fresh MM on at least **three common-success inputs**, with optimal ACL1 ties explicitly eligible. Failure of either threshold retires this fixed policy; no root/pool/cap change follows an intermediate overlap gain. A pass justifies further complete-constructor measurement, not promotion; all-attempt cost and per-input runtime gaps still matter.

**Self-critique.** Common-tree initialization can remain globally congested even when two whole owners are free. Frozen neighbors, four roots/states, a single internal path and early completion can exclude useful placements; strict energy can still impose barriers involving three owners. Degree-dependent boundary scans and repeated Dijkstra may spend the query allowance before a complete child. Root ranking can prefer short-term shared contacts that worsen later capacity. Whole-neighborhood routing and shortest-path trees are conventional; the exact bounded joint policy is an unestablished heuristic, not a novelty claim. Its full-screen failure cannot prove the representation impossible, but would be sufficient to stop refining this policy.
