# Supplied-state free-path augmentation diagnostic

Hypothesis: some remaining missing contacts in C006b's four final partial embeddings can be added by connected paths through unused full-Z12 qubits. Existing chain ownership remains fixed; an augmenting path is assigned entirely to the lower-ranked source endpoint, joining that chain to a neighbor of the other endpoint. Such additions cannot remove an existing contact. This tests a general local operator on saved states, not a constructor or a new full-pipeline candidate.

Use exactly the saved final ER, regular, complete and SBM states (161/232/3/82 missing edges), never the unsaved best states. Before augmentation, enumerate connected components of the unowned target subgraph and every chain's neighboring free components. For each missing original edge, run a deterministic multi-source BFS on unowned sites from neighbors of its first chain to neighbors of its second. A path's cost is its number of newly occupied sites. Record every route or proof that the endpoint component sets do not intersect, both endpoint access counts, and shortest extra-site count.

Sequential diagnostic pseudocode: from the same entry, recompute shortest free paths for every currently missing source edge; choose minimum added sites, then canonical endpoint ranks and deterministic BFS order; attach the path to its first chain; independently recount represented contacts and verify that none was lost; repeat until complete, no route exists, or a common 30-second per-input diagnostic deadline interrupts. Setup, all failed queries, graph checks, selection, copies and final validation are charged. The deadline is a diagnostic cap, not extra C006b solver time. No restart, ownership transfer or alternate assignment attempt is permitted. Preserve partial progress on interruption.

If augmentation reaches a complete original-valid minor, measure an additional deterministic safe-deletion diagnostic: ascending chain/site order, repeated sweeps, deleting only when the chain remains nonempty/connected and every original neighbor contact remains. Keep this cost inside the same deadline and validate the resulting original minor. Otherwise omit deletion. Record added Q, any removed Q, and the distinction between augmentation and deletion validity; no supplied-state time or ACL is a full-candidate/MM comparison.

Cheap falsifier: if there are no initial free routes, reject this operator's premise for these states before implementation. If routes exist but greedy augmentation stalls, reject that fixed sequential policy as sufficient; report access-component and remaining-contact obstructions. Completion would justify a separately specified future integration, with its entire construction and cleanup cost still untested.

Self-critique: many interior chains may not touch any free component. Greedy ownership of a shortest path can block later routes, and assigning it wholly to one endpoint can be unnecessarily costly. Failure does not exclude joint rerouting or other assignments. This diagnostic uses repeatedly examined states chosen after C006b failed, offers no holdout evidence, and measures reach before quality. Source edges and target couplers are original and independently validated; no MM/busclique, converter, native pipeline, cached complete embedding, or global optimization is called.
