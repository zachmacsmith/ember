# Track C: coarsening followed by connected-region splitting

This is a new construction hypothesis, written before implementation. It does not use inherited geometric placement, incremental demand-priced tree routing, MM, busclique, cached embeddings, a global integer program, a portfolio, or graph-family dispatch.

**Hypothesis.** Heavy-edge source aggregation can expose groups whose physical contacts are easier to preserve together. Start with a connected target region representing the entire source, then undo the aggregation by splitting one connected region into two connected child regions while maintaining all contacts required by the current source quotient. After all source vertices are separate, delete unnecessary sites. The possible advantage is that every physical site has a unique owner from the start; construction does not create overlapping chains that later require conflict resolution. The immediate uncertainty is whether local splits leave enough boundary access for later splits.

**Fixed initial mechanism.** Greedily match current source aggregates by strongest inter-aggregate edge weight, with size and seeded rank tie breaks; unmatched disconnected aggregates may be paired without inventing a logical edge. Save the binary hierarchy. The root owns the largest connected target component. Undo merges in reverse order, maintaining the original-source quotient exactly. Each split gives both children at least the sum of their individual degree-based chain lower bounds. A child grows from a seed by transferring boundary sites from the other child. Preserve donor connectivity with a maintained spanning tree, falling back to an explicit articulation/connectivity calculation when leaf transfers cannot advance; preserve every required donor contact. Prioritize acquiring missing recipient contacts, then its source-weighted region size. Try at most six local seed placements for this one split, accepting the first fully certified split. A failed split ends this construction; no alternative constructor or independent best-of run is called. All local attempts share one absolute deadline.

```text
multilevel_embed(G, H, seed, absolute deadline D):
    read structural adjacency; compute source degree bounds using exact max degree(H)
    build one binary heavy-edge aggregation hierarchy of all source vertices
    assign its root the largest connected component of H
    for each saved merge in reverse:
        derive required child-to-current-region contacts from original edges of G
        split the parent region by connected boundary transfers under those contacts
        if no certified split before the local attempt cap or D: return recorded failure
        publish both disjoint connected children; update current source owner map
    certify the complete minor against original G and H
    greedily remove sites while preserving chain connectivity and every original contact
    certify a private final mapping and check D again; late valid outputs get no success credit
```

Every adjacency scan, attempted split/transfer, failed local attempt, validation, and trimming operation is charged to the same solver wall and exposed in diagnostics. The wrapper also reports whole-process wall time. Input decoding/imports follow the existing pilot's common convention. Deadline interruption preserves partial aggregate regions and the last completed stage; these are not valid source embeddings unless independently certified. This implementation will support the supplied graph interface and an absolute `perf_counter` deadline, with no architectural coordinates or family metadata.

**Self-critique and prior art.** Coarsening and uncoarsening are established graph-partitioning ideas, including heavy-edge coarsening; novelty cannot be claimed for that framework. See Karypis and Kumar, *A Fast and High Quality Multilevel Scheme for Partitioning Irregular Graphs* (1998), [author-institution publication record](https://experts.umn.edu/en/publications/a-fast-and-high-quality-multilevel-scheme-for-partitioning-irregu/), DOI [10.1137/S1064827595287997](https://doi.org/10.1137/S1064827595287997). This prototype's proposed research mechanism is contact-constrained connected uncoarsening for minor construction, whose novelty still needs a dedicated prior-art check if results warrant it. A source partition with a small edge cut need not admit a useful physical region partition. Coarse feasible contacts may be concentrated on the wrong future endpoints. Starting from a large target region can also inflate final chain lengths and trimming time. The largest-component restriction can unnecessarily reject disconnected sources on disconnected targets; ideal Z12 is connected, and this restriction must remain explicit rather than a general infeasibility claim. Local seed attempts are alternatives inside one fixed splitting rule, not a method portfolio.

**Cheap falsifier fixed before outcomes.** First run small synthetic correctness cases, including connectedness/contact traps and interrupted/late validation. Then run one fresh, paired-host, seed-0 screen at 15 seconds per method on ideal Z12 using eight existing readiness sources chosen by broad structure: path `ember_2030`, tree `ember_5058`, grid `ember_1584`, random planar `ember_31536`, random ER `ember_6450`, regular `ember_14334`, complete `ember_1041`, and SBM `ember_30736`. This is repeated development data, not a holdout and not coverage of all families. Compare the single `multilevel-regions` configuration with fresh stock MM in separate processes on hyde05, with the pilot's fixed within-pair method shuffle and isolated environments. Keep all eight outcomes, failures, late-valid results and complete timing. If fewer than four of eight produce timely valid embeddings, or all successful pairs lose Q substantially, treat the initial mechanism as falsified for general construction and record which hierarchy depth/contact constraint failed before revising it. A successful tiny case is only a correctness witness. No overall paper or family-mean claim follows from this screen.
