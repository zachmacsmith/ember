# Reserved access does not survive this sequential routing policy

Only the tree reached a complete original-valid minor. Six inputs stalled, and the complete input reached the fixed 1,024-visit cap. There were no errors, timeouts, late successes or rejected actual-data proposals. Every retained assignment has nonempty connected disjoint chains realizing its claimed original-source contact subset P; only the tree realizes the full original graph. No constructor, ownership transfer, cleanup or MM call ran.

Each input used its exact saved reserved initialization and the original full Z12 target. One canonical pass added shortest unused-site paths to the lower-ranked endpoint, preserving all previously realized original contacts. Limits stayed at 30 seconds, 1,024 still-missing visits and 256 commits. The access failure is measurable. Every remaining missing edge in the six stalled inputs lacks a shared unused component. Complete retains 36 reserved sites in 29 components and has 31 unused full-target components. It has only six sealed chains, but 1,170 of its 1,199 missing edges lack shared component access. Its recorded failures are predominantly disconnected access: 755 visits versus 51 with sealed endpoints. Thus giving every chain some initial free neighbor does not preserve useful pairwise routing access.

Complete also retains 393 unattempted edges. A separate saved-data recount finds shared unused components for 29 remaining edges; these are unattempted reach opportunities, not credited repairs. The run remains classified as capped. Its 1,170 inaccessible edges nevertheless rule out completion by further addition-only moves from that final state: unused components cannot merge, and a growing endpoint cannot enter a previously inaccessible component. Raising the visit cap alone cannot repair that obstruction.

The frozen checks passed six routing groups and one saved-data group, including sealing, incidental-contact protection, cap retention, rollback and final-deadline rejection. The initial wrapper-indexing failure is preserved; it was corrected before supplied-state calls. Independent replay checked all 631 committed paths, 639 assignment/access records and 655 original-label gates. The commits realized 986 new source contacts, including 355 incidental contacts protected afterward. All actual access records completed.

Input wall totals 58.925 seconds; diagnostic wall including artifact serialization is 60.295 seconds. Common gates/contact recounts consumed 30.205 seconds, access summaries 23.923 seconds and path searches 3.064 seconds. Saved-data replay cost another 28.063 seconds, separately reported. These intrusive local costs support no constructor/MM timing claim.

The [fixed policy](c_reserved_access_routing_diagnostic.md), [reconciled outcomes](../../../results/codex/track-c-reserved-access-routing/analysis001/summary.json), [all visits](../../../results/codex/track-c-reserved-access-routing/analysis001/visits.csv), [stage costs](../../../results/codex/track-c-reserved-access-routing/analysis001/stages.csv) and [raw paths/maps](../../../results/codex/track-c-reserved-access-routing/results.json) preserve the full evidence. Reject this fixed reserve-then-greedy-addition policy as sufficient, not every constructor using reserved space. Any next mechanism must address access destruction during routing; this result does not justify a full constructor or establish novelty.
