# Probe scripts (archived 2026-09-03, s3.127)

The measurement scripts of s3.20–s3.126. They drove the old engine's
`AttractConfig` knobs, which no longer exist: they are records of what was
asked and how, not runnable code. Their CSV/log outputs stay in
`docs/paper2/data/`. The live harnesses are `docs/paper2/data/plane_fingerprint.py`
and the s3.127 board scripts.
