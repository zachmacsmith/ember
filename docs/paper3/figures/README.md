# paper3 figures

All three are generated by one deterministic script from `docs/paper3/data/e0_crossover.csv`
(E0 §4.1 + the §4.1b extension rows; 8,559 rows). Conventions per `protocol.md`: `acl_spur`
column for every arm (rule 3); paired ΔACL on both-succeed (instance, seed) pairs only,
deterministic arms pairing against every minorminer run on the same instance (rule 4);
success rates separate and unpaired; `clique` collapsed into `template` (identical acl_spur
on all co-successes, §4.1); "best non-MM arm" = best of the three §4.1 strategy families
{template, clmm, attraction} (pssa ≈ template ± polish and the mmfork-cuthill control are
excluded from "best"). Vector PDF + 200 dpi PNG for each.

- `fig_crossover_map.{pdf,png}` — the centerpiece: P16/Z12 grids over (n, p) colored by the best non-MM arm's median paired ΔACL_spur% vs minorminer (blue = better, red = worse; scale asymmetric −34..+5 because only 3 cells anywhere are red, max +1.4%), winner letters T/C/A, hatched frontier cells (MM 0-for-all), grey all-fail cells, collapsed ≥260 column, and the p*(n) crossover line (§4.1 outputs 1–2, §4.1b straddle; frontier per output 4). Regenerate: `.venv/bin/python docs/paper3/data/fig_crossover.py`
- `fig_ladders.{pdf,png}` — the mechanism: P16 n ∈ {100, 140, 180} median ACL_spur vs p (log x, IQR bands) for minorminer/template/clmm/attraction with per-panel p* markers — template density-flat while MM climbs and then dies (open markers + k/N = partial success; §4.1 output 2 "headroom = MM's density sensitivity", cliff per output 4). Regenerate: `.venv/bin/python docs/paper3/data/fig_crossover.py`
- `fig_frontier.{pdf,png}` — the feasibility ceiling: success rates (k/N annotated; unequal attempts by design) at the nine past-cliff cells for minorminer/clmm/template/pssa, template `infeasible` flagged where n > max clique, with the Z12 K184 12.98-vs-MM-K140 15.09 and P16 K180 16.64-vs-K140 19.77 callout (§4.1 outputs 3–4: clmm-only overflow band at n=200–220, busclique bound K184/K180). Regenerate: `.venv/bin/python docs/paper3/data/fig_crossover.py`
- `fig_m4_forest.{pdf,png}` — the M4 frozen-eval headline (§4.10 / `m4_headline.txt` Table 1): forest plot over the 14 frozen cells (grouped P16/Z12, sparse→dense) of median paired ΔACL_spur% vs minorminer for p3-ate/p3-clmm/p3-mmpolish, with bootstrap 95% CIs over the both-succeed (inst_seed, algo_seed) paired deltas recomputed from `m4_eval.csv` (10,000 resamples, fixed seeds; per-pair Δ% convention, cross-checked against Table 1); filled marker = Holm-corrected p < 0.05, hollow = not; K_n cells flagged "n = 5 pairs"; K180/K179 drawn as no-pair frontier rows (MM 0/5, ate/clmm 5/5). Regenerate: `.venv/bin/python docs/paper3/data/fig_final.py`
- `fig_m5_verdicts.{pdf,png}` — the M5 full-library category outcome summary (§4.11, counts verbatim from notes.md): WIN/tie/LOSS over the 35 graph families for P16-merged/Z12/C16 × {p3-ate, p3-clmm, p3-mmpolish} as end-anchored stacked bars (WIN blue from the left, tie neutral, LOSS red to the right — the crossover map's diverging semantics; WIN counts labeled; mmpolish 18/17/0 on P16 called out as zero losses), captioned with the §4.11 decomposition of residual losses into the measured seed-noise null + documented boundaries. Regenerate: `.venv/bin/python docs/paper3/data/fig_final.py`
